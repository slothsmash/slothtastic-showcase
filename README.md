# slothtastic-showcase

Slothtastic is a creative tool that includes a text editor, ideation boards, timeline creationg, painting, AI-powered features and an internal search engine. All of the files can be automatically synchronized to your preferred cloud storage or saved to your local device depending on your preferences.

The tool supports writing texts in both Markdown and as html code and integrates a standard tet editor UI.
